Legacy Migration Lab
====================
Use the following synthetic legacy report requirements for Day 9.

Legacy report: Regional Sales Performance (Cognos-style)
Metrics: Revenue, Cost, Profit, Margin %, Orders
Attributes: Year, Quarter, Month, Region, Product Category
Prompt/filter: Year, Region
Drill: Region -> Customer detail
Expected behavior: KPI values must reconcile to FactSales.csv.

Migration objective:
1. Inventory report components.
2. Map each component to Power BI.
3. Recreate model and DAX.
4. Validate totals against SQL/CSV.
5. Document any assumptions or gaps.
